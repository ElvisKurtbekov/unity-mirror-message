# Система сетевых сообщений с подписками (Mirror + Zenject)

Тестовое задание: реализация системы обмена сетевыми сообщениями между клиентом и сервером с использованием Unity, Mirror и Zenject.

## Описание

Проект реализует простую систему сетевых сообщений, в которой:

1. Клиент подключается к серверу
2. Клиент отправляет запрос на подписку на определённый тип сообщения
3. Сервер регистрирует подписку клиента
4. Сервер отправляет сообщение только подписанным клиентам
5. Клиент получает сообщение и выводит его в консоль
